# thermocouple-coefficients.md — ITS-90 열전대 계수 근거 (사람 검증 게이트)

구현 규칙: 아래 표에 출처가 기재된 타입만 `packages/engine/src/thermocouple.ts`에 구현한다.
**이 파일에 없는 계수는 구현하지 않는다.** (벤더/표준 상수 검증 게이트)

**중요**: 열전대는 틀린 계수를 써도 오류가 나지 않는다. 그럴듯한 온도가 그냥 나온다.
교정 현장에서 이건 에러보다 나쁘다. 특히 **K형은 0 °C 위에서 지수항이 따로 붙는데**,
이걸 빼먹으면 100 °C에서 약 109 µV(≈ 2.7 °C) 낮은 값이 조용히 나온다.

### 미구현 근거: 색상 코드

NIST Monograph 175는 열전대 **피복 색상 코드를 규정하지 않는다**. 색상은
ANSI/ASTM E230, IEC 60584-3 등 국가·규격별로 서로 다르다. NIST 근거가 없으므로
`THERMOCOUPLE_TYPES` 메타데이터에 **색상 필드를 넣지 않았다.** 넣으려면 해당 규격
문서를 이 파일에 별도 절로 기재할 것.

## 2. 구현 완료 — 정함수 (온도 → 전압)

전압 단위 mV, 온도 ITS-90 °C, **기준 접점 0 °C**. 계수는 `c_0`부터 오름차순.
Monograph 175는 계수를 µV 단위로 싣고 `allcoeff.tab`은 mV 단위로 싣는다 (1000배 차이).
엔진은 **mV**를 쓴다.

| 타입 | 재질 (Monograph 175 장 제목) | 정함수 범위 (°C) | 소구간 경계 (°C) | 계수표 |
|---|---|---|---|---|
| B | Platinum-30% rhodium vs. platinum-6% rhodium | 0 ~ 1820 | 0 / **630.615** / 1820 | 표 2.3.1 |
| R | Platinum-13% rhodium vs. platinum | −50 ~ 1768.1 | −50 / **1064.18** / **1664.5** / 1768.1 | 표 3.3.1 |
| S | Platinum-10% rhodium vs. platinum | −50 ~ 1768.1 | −50 / **1064.18** / **1664.5** / 1768.1 | 표 4.3.1 |
| E | Nickel-chromium vs. copper-nickel | −270 ~ 1000 | −270 / **0** / 1000 | 표 5.3.1 |
| J | Iron vs. copper-nickel | −210 ~ 1200 | −210 / **760** / 1200 | 표 6.3.1 |
| K | Nickel-chromium vs. nickel-aluminum | −270 ~ 1372 | −270 / **0** / 1372 | 표 7.3.1 |
| N | Nickel-chromium-silicon vs. nickel-silicon-magnesium | −270 ~ 1300 | −270 / **0** / 1300 | 표 8.3.1 |
| T | Copper vs. copper-nickel | −270 ~ 400 | −270 / **0** / 400 | 표 9.3.1 |

식은 전부 `E = Σ c_i · t₉₀ⁱ` 이다. **단, K형 0 °C 초과 구간만 예외** (§3).

### 소구간 선택 규칙

경계값은 **아래쪽 구간**에 속한다 (NIST가 표를 나열한 순서와 같다).
예: K형 0 °C는 −270~0 구간으로 계산한다. 두 구간이 0 °C에서 같은 값을 주므로 결과는 같다.

## 3. K형 지수항 (절대 누락 금지)

Monograph 175 **표 7.3.1**, `allcoeff.tab` `exponential:` 블록.

**0 °C 초과 구간에서만** 다항식에 다음 항을 더한다:

```
E += a₀ · exp( a₁ · (t₉₀ − a₂)² )
```

| 상수 | Monograph 175 (µV 기준) | 엔진 값 (mV 기준) |
|---|---|---|
| a₀ | 1.185976 × 10² µV | **0.1185976 mV** |
| a₁ | −1.183432 × 10⁻⁴ | **−1.183432e−4** (단위 무관, °C⁻²) |
| a₂ | 126.9686 | **126.9686** (°C) |

- `t₉₀ = a₂ = 126.9686 °C`에서 이 항은 정확히 a₀만큼 기여한다.
- 100 °C에서 기여분은 **약 108.82 µV**. 빼먹으면 3987.41 µV가 나오는데,
  NIST 기준표 값은 **4096.2 µV**다. 약 2.7 °C 낮은, 겉보기 멀쩡한 오답.
- **K형 외의 어떤 타입에도 지수항이 없다.** 테스트가 이를 강제한다.

## 4. 구현 완료 — 역함수 (전압 → 온도) 및 오차 범위

역함수는 **근사식**이다. NIST가 소구간마다 잔차 범위를 함께 공표하며,
엔진은 이 값을 결과에 실어 보낸다. 정함수와 정확한 역관계가 **아니다** —
왕복 계산은 아래 범위만큼 어긋난다. 테스트에서 등호 단언 금지.

### 역함수 범위 ≠ 정함수 범위

역함수가 정함수보다 **좁다**. 이건 구현 누락이 아니라 NIST가 그만큼만 공표한 것이다.
범위 밖은 **외삽하지 않고 거절**한다.

| 타입 | 정함수 범위 | 역함수 범위 |
|---|---|---|
| K | −270 ~ 1372 °C | **−200** ~ 1372 °C |
| E | −270 ~ 1000 °C | **−200** ~ 1000 °C |
| N | −270 ~ 1300 °C | **−200** ~ 1300 °C |
| T | −270 ~ 400 °C | **−200** ~ 400 °C |
| B | 0 ~ 1820 °C | **250** ~ 1820 °C |
| J, R, S | (동일) | (동일) |

## 5. 교차 검증 결과

`allcoeff.tab`(아카이브 경유)의 모든 값을 1차 출처와 대조했다.

1. **계수 대조** — K형 전 계수(−270~0 구간 11개, 0~1372 구간 10개, 지수항 3개)를
   Monograph 175 표 7.3.1 원문과 1:1 대조하여 전부 일치 확인.
2. **기준표 대조** — 8개 타입 전부에 대해 Monograph 175 표 x.3.3의 기준표 값
   (µV, 기준 접점 0 °C)을 구현 결과와 비교. **74개 지점 전부 일치.**
   0.01~0.1 µV 자리까지 인쇄된 71개 지점은 편차 0.05 µV 이하,
   J형 표가 760 °C 위에서 1 µV 단위로만 인쇄하는 3개 지점(800·1000·1200 °C)은
   편차 0.5 µV 이하. 해당 값들은 `packages/engine/vectors/thermocouple.json`에
   `$quoted`로 보존했고, 인쇄 자릿수가 다른 3개 지점은 별도 허용오차를 갖는다.
3. **역함수 오차 대조** — 8개 타입 23개 소구간 전부에 대해 온도를 400스텝으로 훑어
   `t → E → t` 잔차를 측정. **23개 구간 전부 NIST 공표 오차 범위 안에 들어옴.**
   공표 범위가 비대칭이고(예: K형 −0.05 ~ +0.06) 좁은데도 전부 맞아떨어진 것은
   정계수·역계수 양쪽이 정확히 옮겨졌다는 강한 방증이다.

소스 코드의 계수 리터럴은 NIST의 `0.xxxE±nn` 표기를 그대로 유지했다.
원문과 한 줄씩 눈으로 대조할 수 있게 하기 위한 것이니 "정규화"하지 말 것.
NIST가 자리를 맞추려고 넣은 **말미의 0 계수도 그대로 둔다.**

## 6. 판단이 필요했던 지점 (`[결정]`)

### 6.1 `[결정]` B형 상한 표기 불일치 — 출처 내부 모순

`allcoeff.tab`의 B형 역함수 절은 **머리말 주석과 표 본문이 다르다**.

- 주석: `700. to 1800.      2.431 to 13.820`
- 표 본문: `Temperature Range: 700. / 1820.`

**1820을 채택**했다. 근거: 전압 상한 13.820 mV는 정함수로 계산하면
E(1820 °C) = 13820.28 µV로 **1820 °C에 대응**한다. E(1800 °C)는 약 13591 µV이므로
주석의 1800은 오식이다. Monograph 175 본문의 B형 범위도 0~1820 °C다.

### 6.2 `[결정]` R·S형 역함수 소구간 겹침

R형은 1.923~13.228 mV 구간과 11.361~19.739 mV 구간이 **겹친다** (11.361~13.228).
S형도 마찬가지 (10.332~11.950). NIST는 겹침 해소 규칙을 명시하지 않는다.

**NIST가 나열한 순서대로 처음 맞는 구간을 쓴다.** 겹침 영역에서는 두 다항식 모두
각자의 공표 오차 안에 있으므로 어느 쪽도 틀리지 않다. 결과에 실제 사용한 소구간을
실어 보내므로 UI에서 어느 다항식이 적용됐는지 표시할 수 있다.

### 6.3 `[결정]` 공표 전압 경계의 반올림 보정

NIST는 역함수 전압 경계를 **0.001 mV로 반올림해서** 싣는다. 그래서 타입 최외곽에서
공표 경계가 실제 기준함수 값보다 몇 십분의 1 µV 안쪽에 놓인다.

예: K형 정격 상한 1372 °C의 정확한 기전력은 **54.8864 mV**인데 공표 상한은 **54.886 mV**다.
공표값을 곧이곧대로 쓰면 **정격 상한에 놓인 열전대를 거절**하게 된다.

**표시용 경계는 NIST 공표값 그대로 두고, 구간 선택만 최외곽에서 정확한 끝점 전압까지
허용**한다. 이건 NIST 자신의 반올림을 되돌리는 것이지 적합 구간 밖으로 나가는 게 아니다.
차이는 항상 1 µV 미만이며, 테스트가 이 조건을 검사한다.

### 6.4 `[결정]` B형은 상온 부근에서 역함수가 성립하지 않음

B형 E(t)는 0 °C에서 출발해 **음으로 내려갔다가 약 21 °C에서 되돌아온다**.
같은 전압이 두 온도에 대응하므로 역함수가 정의되지 않는다. NIST가 B형 역함수를
250 °C부터만 공표하는 이유다. 0.291 mV 미만은 거절한다 — 이건 구현 한계가 아니라
물리적 다가성이다.

## 7. 냉접점 보상 (CJC)

열전대는 **두 접점의 차이만** 만든다. 측정 전압은 냉접점이 0 °C가 아닌 만큼 이미 깎여 있다.

```
V_total = V_measured + E(T_cold)     →  T_hot = 역함수(V_total)
```

**온도를 더하면 안 된다.** 검증 벡터에 넣어둔 사례:
K형, 열접점 300 °C(12208.6 µV), 냉접점 25 °C(1000.2 µV) → 측정값 11.2084 mV.

- 올바른 계산: 300.0 °C
- 전압 대신 **온도를 더한 경우**: 275.80 + 25 = **300.80 °C** (0.80 °C 오차)

K형은 이 구간에서 거의 선형이라 오차가 작게 나온다. 그래서 벤치 점검을 통과하고
나중에 교정 오프셋으로 나타난다. 테스트가 이 실패 모드를 명시적으로 붙잡고 있다.

### 기재할 때 필요한 항목

1. NIST(또는 해당 표준화 기구) 문서명·문서번호·판년도
2. 계수가 실린 **표 번호**
3. 소구간 경계와 단위 (µV인지 mV인지 반드시 명시)
4. 역함수라면 공표 오차 범위
5. 1차 출처와의 대조 결과 (어떤 표의 몇 개 지점을 확인했는지)
