# ntc-thermistor.md — NTC 서미스터 벤더 상수 근거 (사람 검증 게이트)

구현 규칙: 아래에 출처가 기재된 곡선만 `packages/engine/src/thermistor.ts`의
`NTC_REFERENCE_CURVES`에 넣는다. **이 파일에 없는 파트 번호·계수·R/T 표는 구현하지 않는다.**
(CLAUDE.md §5-3 벤더 상수 검증 게이트)

**중요**: 서미스터는 틀린 상수를 써도 오류가 나지 않는다. 그럴듯한 온도가 그냥 나온다.
Beta 식은 특히 그렇다 — 앵커 온도(보통 25 °C) 근처에서는 어떤 B 값을 넣어도 맞는 것처럼
보이고, 범위 끝에서만 몇 도씩 틀린다. 그래서 이 툴의 기본 동작은 두 모델의 차이를
같이 보여주는 것이다.

---

## 1. 이 파일이 담보하는 범위

엔진의 **수식 자체는 벤더 상수가 아니다** — Beta 식과 Steinhart-Hart 식, 3점 피팅,
Cardano 역해는 모두 공개된 수학이고 이 저장소에서 새로 구현했다. 이 파일이 게이트하는
것은 딱 하나, 아래 §2의 **실측 R/T 표 1종**이다.

- 툴은 이 표 없이도 완전히 동작한다(사용자가 3점을 직접 입력).
- 표는 ①피팅 예제 프리셋 ②골든 벡터(피팅이 자기가 못 본 점까지 재현하는지 검증)에만 쓰인다.

### 2.2 표 자체 정합성 확인

표에서 B를 역산해 데이터시트가 인쇄한 B25/85와 대조:

```
B25/85 = ln(10000 / 1070) / (1/298.15 − 1/358.15) = 3977.51 K
데이터시트 인쇄값: 3977 K (공차 0.75 %)  → 일치
```

같은 표에서 짝을 바꿔 뽑은 B (이 툴의 핵심 논지):

| 짝 | B (K) |
|---|---:|
| B−40/25 | 3746.07 |
| B25/50 | 3931.98 |
| B25/85 | **3977.51** |
| B25/100 | 3993.64 |
| B25/125 | 4018.55 |

즉 **한 부품에서 B가 272 K 범위로 흩어진다.** "B = 3977 K"만 적힌 값은 어느 두 온도
사이인지 없으면 재현 불가. 엔진이 `betaLowC`/`betaHighC`를 같이 들고 다니는 이유.

## 3. 구현하지 않은 것 (근거 없음/범위 밖)

- **데이터시트의 A·B·C·D / A1·B1·C1·D1 계수 (§"PARAMETER FOR DETERMINING NOMINAL
  RESISTANCE VALUES", curve 1~13)**: 이건 표준 3항 Steinhart-Hart가 아니라 Vishay 확장형
  (`R(T) = Rref·exp(A + B/T + C/T² + D/T³)`, 역식은 ln(R/Rref)의 3차식)이다. 폼이 다르므로
  이 엔진의 `SteinhartHartCoefficients`에 그대로 넣으면 틀린다. **미구현**.
  넣으려면 별도 함수와 별도 테스트가 필요하고, 이 절을 먼저 확장할 것.
- **다른 벤더·다른 파트 (Murata, EPCOS/TDK, Semitec 등)**: 데이터시트 미확보. **미구현**.
  추가하려면 위 §2와 같은 표(문서번호·리비전·URL·전사표·정합성 확인)를 여기에 먼저 채운다.
- **다른 R25 열 (2.2 k ~ 6.8 k 등) 및 다른 curve (1~8, 10~13)**: 전사·검증 비용 대비
  가치 없음. **미구현** (필요해지면 같은 PDF에서 추가 가능).
- **자기가열(dissipation constant), 열시정수, 공차 등급**: 계산에 안 쓰임. **미구현**.

## 4. 툴이 주장해도 되는 수치 (전부 위 표에서 파생, 재현 절차 포함)

`-40 / 25 / 125 °C` 세 점으로 3항 Steinhart-Hart를 피팅한 뒤, **피팅에 안 쓴 36행을 포함해
39행 전체**와 대조한 결과:

```
A = 1.138449457e-03   B = 2.325188439e-04   C = 9.469821107e-08
최대 오차 +0.1097 °C (150 °C), RMS 0.0384 °C, 39행 전체
```

같은 절차를 `20 / 25 / 30 °C` (10 K 간격)로 하면:

```
최대 오차 0.4392 °C (150 °C), RMS 0.1442 °C
```

Beta 식(B = 3977 K, 10 kΩ @ 25 °C)을 위 피팅 곡선과 비교하면:

| °C | Beta 식이 읽는 온도 | 편차 |
|---:|---:|---:|
| −40 | −37.01 | **+2.99** |
| 0 | +0.74 | +0.74 |
| 25 | 25.00 | 0.00 (앵커) |
| 85 | 85.06 | +0.06 (B의 두 번째 온도) |
| 150 | 152.72 | **+2.72** |

이 수치들은 `packages/engine/vectors/thermistor.json`에 골든 벡터로 고정되어 있고,
Python `decimal`(50자리)로 엔진과 독립적으로 계산했다. 툴 페이지의 설명 문구는
**이 표 밖의 수치를 주장하지 않는다.**
